# Desafio NotebookLM: A Filosofia de Benjamin Graham

Este repositório contém um miniguia de estudo sobre o "Value Investing", baseado nas obras e ensinamentos de Benjamin Graham, curados via IA NotebookLM.

## 🎯 Objetivos de Estudo
- Definir a diferença entre Investimento e Especulação.
- Compreender o conceito de "Sr. Mercado".
- Aprender a calcular e aplicar a "Margem de Segurança".

## 📚 Fontes Base
- Resumos estruturados de *O Investidor Inteligente*.
- Cartas selecionadas de Warren Buffett sobre os ensinamentos de Graham.
- Artigos técnicos sobre análise fundamentalista.

## 🛠️ Ferramentas
- **IA:** NotebookLM (Google) para síntese e correlação de fontes.
- **Metodologia:** Aprendizagem Ativa com prompts estruturados.
